ANÁLISIS DE CVEs (17 total):

[CRÍTICO] CVE-2024-6387 — regreSSHion
  - Software: OpenSSH < 8.8 (servidor tiene 8.7)
  - CVSS: 8.1 (CVSS v3.1) — Remote Code Execution sin autenticación
  - Descripción: Race condition en signal handler de sshd. Permite RCE como root
    en sistemas con glibc (típicamente Linux). Reintroducción de CVE-2006-5051.
  - Impacto: Toma de control del servidor sin credenciales.

[CRÍTICO] CVE-2023-38408 — OpenSSH ssh-agent RCE
  - Software: OpenSSH (componente ssh-agent)
  - CVSS: 9.8 — Remote Code Execution
  - Descripción: Permite a un servidor SSH malicioso cargar librería arbitraria
    vía ssh-agent forwarding.
  - Impacto: RCE al conectarse a servidor malicioso con agent forwarding activo.

[ALTO] CVE-2023-48795 — Terrapin Attack
  - Software: OpenSSH 8.7 (afectado)
  - CVSS: 5.9 — Protocol Downgrade / Man-in-the-Middle
  - Descripción: Ataque activo de MitM que puede desactivar extensiones de
    seguridad SSH durante el handshake (ataque al prefix truncation del protocolo).
  - Impacto: Posible downgrade de algoritmos criptográficos.

[ALTO] CVE-2023-51385 — OpenSSH command injection
  - Software: OpenSSH 8.7
  - CVSS: 6.5 — Command injection via ProxyCommand/ProxyJump
  - Descripción: Inyección de comandos a través de nombres de host con caracteres
    especiales en configuración ProxyCommand.

[ALTO] CVE-2025-26465 — OpenSSH client MitM (2025)
  - Software: OpenSSH cliente
  - CVSS: 6.8 — Man-in-the-Middle
  - Descripción: Permite aceptar clave de host no autorizada si VerifyHostKeyDNS=yes.

[ALTO] CVE-2025-32728 — OpenSSH (2025)
  - Software: OpenSSH
  - CVE 2025 — detalles exactos pendientes de verificación manual en NVD

[MEDIO] CVE-2021-41617 — OpenSSH privilege escalation
  - CVSS: 7.0 — Escalada de privilegios local
  - Descripción: sshd falla al inicializar grupos suplementarios correctamente,
    permitiendo escalada en ciertas configuraciones.

[MEDIO] CVE-2021-36368 — OpenSSH auth bypass (trivial)
  - CVSS: 3.7 — Bypass de autenticación trivial
  - Descripción: Permite ignorar flag de fallos de auth en keyboard-interactive.

[LEGADO] CVE-2023-51767 — SSH auth timing
  - Timing attack en autenticación SSH

[LEGADO] CVE-2016-20012, CVE-2008-3844, CVE-2007-2768
  - CVEs históricos de OpenSSH, probablemente false positives del scanner o
    afectan funcionalidades específicas no activas.

CVEs 2026 (CVE-2026-35414, CVE-2026-35385/86/87/88):
